# Netflix ML Dashboard

A full-stack machine learning dashboard for analyzing Netflix data.

## Project Structure
- `data/`: Datasets
- `model/`: ML training scripts and serialized models
- `backend/`: Flask server and API endpoints
- `frontend/`: UI files (HTML/CSS/JS)
- `templates/`: Flask HTML templates

## Run Locally
Use `start.bat` on Windows or `run.sh` on Linux/Mac to start the project.
